# MyGuide

MyGuide is a Flutter-based tourism and navigation application designed specifically for visitors exploring Pretoria CBD.

The application helps users discover places to visit, find useful information about attractions, and navigate around Pretoria CBD.

## Main Features

* User registration and login
* Explore tourist attractions
* View restaurants and places of interest
* Discover historical sites
* Discover parks and museums
* Interactive map and navigation
* Safety information
* Quick access to important features
* Simple and user-friendly interface

## Technologies Used

* Flutter
* Dart
* Android Studio / Visual Studio Code
* Firebase / Database 

## Project Structure

The project is organised into different folders to make the application easier to manage.

lib/
├── main.dart
├── screens/
├── widgets/
├── theme/
├── models/
└── services/


### Screens

The `screens` folder contains the different pages of the application, such as:

* Splash Screen
* Login Screen
* Register Screen
* Home Screen
* Explore Screen
* Map Screen
* Profile Screen

### Widgets

The `widgets` folder contains reusable components that are used across different screens.

### Theme

The `theme` folder contains the application's colours, fonts and other design settings.

### Models

The `models` folder contains classes used to represent application data.

### Services

The `services` folder will contain functionality that connects the application to external services or a database.

## Getting Started

To run the project, make sure Flutter is installed on your computer.

Clone or download the project and open it in Visual Studio Code or Android Studio.

Run the following commands in the terminal:

bash
flutter pub get
flutter run


Make sure an Android emulator or a physical Android device is connected before running the application.

## Project Purpose

The purpose of MyGuide is to provide visitors with a simple way to discover and navigate tourist destinations in Pretoria CBD from one application.
